ICT807 WEB TECHNOLOGIES
ASSESSMENT 3 – WEBSITE PORTFOLIO

PROJECT:
Health & Fitness Tracker

TECHNOLOGIES:
- HTML5
- CSS3
- JavaScript
- Node.js
- Express.js
- JSON data storage
- Chart.js

HOW TO RUN:

1. Open the project folder in Visual Studio Code.

2. Open the terminal.

3. Install dependencies:
   npm install

4. Start the server:
   npm start

5. Open a browser and visit:
   http://localhost:3000

IMPORTANT:
The website should be accessed through the Node.js server rather than
opening the HTML files directly.

FEATURES:
- 10-page responsive website
- Exercise tracking
- Nutrition tracking
- Sleep tracking
- Fitness dashboard
- Progress charts
- Goal management
- Contact form validation
- Dynamic data loading
- Backend API
- Responsive navigation
- Semantic HTML5
- Accessibility features

PRIVACY:
The project is an educational application. The contact form validates
input but does not permanently store contact information.

DISCLAIMER:
This project is for educational purposes and does not provide medical
diagnosis or professional medical advice.
