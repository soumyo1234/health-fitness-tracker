About the Project

Understanding the purpose and design of the application.

Purpose

The Health & Fitness Tracker is a responsive web application designed to help users organise basic wellbeing information. The system allows users to record exercise, nutrition, sleep and personal goals.

Target Audience

The application is aimed at students, working adults and general users who want a simple digital method for tracking everyday health-related habits.

Technology

The system uses HTML5 for semantic structure, CSS3 for responsive presentation, JavaScript for interaction and Node.js with Express for simple server-side data handling.
